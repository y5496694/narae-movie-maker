나래 무비메이커 1.0.0 — Windows x64

실행
  나래 무비메이커.cmd: 한국어 데스크톱 편집기 (이동 가능한 실행기)
  나래 무비메이커.lnk: 현재 폴더용 바로가기
  narae.cmd: 독립 CLI

CLI 패키지는 CartCut, 나래 GUI 설치·실행, 별도 Node.js 설치 없이 작동합니다.
runtime 폴더에는 CLI가 직접 실행하고 종료하는 Chromium/Electron 렌더 엔진과
FFmpeg/FFprobe가 들어 있습니다. Canvas, WebGL, HTML 그래픽 등 원본의 실제
편집·합성 코드를 사용하며 마우스/키보드 자동 조작은 사용하지 않습니다.
CLI와 runtime 폴더는 함께 두세요.

빠른 시작 (이 폴더에서 PowerShell)
  .\narae.cmd doctor
  .\narae.cmd new demo.nmm --width 1080 --height 1920 --fps 30 --seconds 5
  .\narae.cmd title demo.nmm "나래 무비메이커" --start 0 --seconds 5 --font-size 72
  .\narae.cmd render demo.nmm demo.mp4
  .\narae.cmd inspect demo.nmm

다시 같은 이름으로 출력할 때에는 --overwrite를 명시합니다.
새 .nmm 프로젝트는 기존 .ngt 형식과 같은 프로젝트 구조이며 .ngt도 열 수 있습니다.
프로젝트에 원본 미디어의 경로가 들어 있으므로 원본 파일을 함께 보관하세요.

편집
  .\narae.cmd add demo.nmm "C:\영상\소스.mp4" --start 0
  .\narae.cmd tools --names
  .\narae.cmd tools --describe trim_clip
  .\narae.cmd edit demo.nmm trim_clip @trim.json
  .\narae.cmd run examples\간단한_숏츠.json --result result.json

new/title/add의 --start와 --seconds는 초입니다.
도구 JSON 및 레시피의 startMs/durationMs 등은 밀리초입니다.
add의 --seconds는 정지 이미지 길이이며 동영상·음원은 실제 소스 길이를 읽습니다.
동영상을 줄이려면 trim_clip을 사용합니다.

레시피 형식
  version: 1
  project: 기존 프로젝트 경로(선택)
  configure: width, height, fps, durationMs, backgroundColor, exportSettings
  steps: [{id, tool, args}, ...]
  saveProject: 프로젝트 저장 경로(선택)
  overwrite: 기존 프로젝트 덮어쓰기 허용 여부
  export: {path, overwrite, settings, timeoutMs}(선택)

앞 단계의 결과는 {"$ref":"media.created.0"}처럼 참조합니다.
레시피의 project/saveProject/export.path와 add_media.items[].path 상대 경로는
레시피 파일이 있는 폴더를 기준으로 해석합니다. 그 밖의 도구 파일 경로는
절대 경로를 사용하세요. tools --describe로 각 명령의 실제 스키마를 확인하세요.
export_video를 steps에 넣어도 출력 완료를 기다립니다.
프록시·역재생 등 생성 자산은 CLI의 프로젝트별 영구 캐시에 보관됩니다.
같은 프로젝트에 대한 병렬 쓰기는 피하고 한 작업씩 실행하세요.

출력 설정
  MP4 / MOV / WebM / GIF를 출력 확장자로 선택합니다.
  .\narae.cmd render demo.nmm demo.webm
  .\narae.cmd render demo.nmm demo.mov
  .\narae.cmd render demo.nmm demo.gif
  .\narae.cmd render demo.nmm demo.mp4 --settings export-settings.json

export-settings.json 예:
  {"videoCodec":"h264","qualityMode":"crf","crf":20,"preset":"fast",
   "audioCodec":"aac","audioBitrate":192,"sampleRate":48000,"channels":2}
설정은 GUI와 동일한 정규화·호환성 규칙을 적용합니다. 다른 컨테이너로 바꾸면
해당 형식의 기본 코덱을 선택하고 명시한 settings를 적용합니다.

독립 녹화
  .\narae.cmd devices
  .\narae.cmd record-screen screen.mp4 --seconds 10 --fps 30
  .\narae.cmd record-screen region.mp4 --seconds 10 --region 0,0,1080,1920
  .\narae.cmd record-camera camera.mp4 --seconds 10 --video-device "장치 이름"
  .\narae.cmd record-audio voice.wav --seconds 10 --audio-device "마이크 이름"
명령 끝의 --dry-run으로 녹화 없이 FFmpeg 명령 구성을 확인할 수 있습니다.
마이크는 --audio-device를 명시한 경우에만 사용합니다. Ctrl+C로 자기 녹화만
중단합니다. 유한한 --seconds와 출력 파일이 필수입니다.

MCP
  .\narae.cmd mcp
표준 입출력 MCP 서버이며 GUI/HTTP 서버 없이 동작합니다.
  narae_describe_tools: 108개 실제 편집 도구의 설명·JSON 스키마 조회
  narae_run_job: 위 레시피를 실행하여 생성·편집·저장·렌더링
GUI 내부 MCP는 별도로 127.0.0.1:9827에서 제공됩니다.
원본 CartCut의 9826 서버와 분리되어 있습니다.
Codex에서 등록된 narae 서버를 쓸 수 있으며 새 연결 반영은 새 채팅에서 확인하세요.

외부 기능과 기기
일반 편집·자막·효과·합성·파일 출력은 로컬 엔진으로 실행됩니다.
로컬 TTS는 Supertonic-3 모델을 처음 사용할 때 다운로드합니다.
STT는 선택한 Whisper 서버/OpenAI 키 또는 지원되는 Apple 런타임이 필요합니다.
AI 배경 제거/클라우드/확장 기능은 원본의 모델·네트워크·계정·확장 조건을 따릅니다.
하드웨어 인코더, 카메라·마이크, Apple 전용 기능은 지원 장치/운영체제가 필요합니다.
본 배포는 Windows x64용입니다. Linux/macOS 소스도 보존했지만 실행 파일은
해당 플랫폼에서 별도로 빌드해야 합니다.

설정 위치
  .\narae.cmd config path
  .\narae.cmd config set KEY VALUE
기본: %APPDATA%\narae-movie-maker-cli
NARAE_CONFIG_HOME으로 다른 설정 폴더를 사용할 수 있습니다.
진단용 NARAE_KEEP_RUNS=1은 임시 작업 로그를 보존합니다.
