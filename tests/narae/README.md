# 나래 독립 CLI 통합 검증

`node tests/narae/create-fixtures.mjs`는 별도 검증 폴더에 3초 MP4 두 개, PNG, WAV, 한글 SRT와 절대 경로 JSON 작업 여섯 개를 만듭니다. 원본 GUI 프로젝트를 열거나 변경하지 않습니다. 두 번째 인수로 검증 폴더를 지정할 수 있습니다. FFmpeg와 FFprobe의 경로를 바꾸려면 `NARAE_TEST_FFMPEG`, `NARAE_TEST_FFPROBE`를 사용합니다.

각 작업은 `narae run <이름>.job.json --result <이름>.result.json`으로 실행합니다. GUI를 종료한 상태에서 실행하고, `reopen`은 `visual` 뒤에 실행합니다. 완료 후 `node tests/narae/verify-results.mjs <검증 폴더>`를 실행하면 모든 단계의 성공 여부와 미디어 누락, 저장, 영상 크기, 영상 길이, 오디오 스트림, 자막 왕복, 프로젝트 재열기 결과를 검증합니다. 폴더 뒤에 `visual editing`처럼 작업 이름을 추가하면 일부만 검증합니다.

개발용 소스에서 한 번에 실행하려면 먼저 메인 코드와 렌더러를 빌드한 뒤 `node tests/narae/run-all.mjs <검증 폴더>`를 사용합니다. 각 CLI 실행을 순서대로 기다리고, 결과와 로그를 보관하고, 성공한 작업에는 검증기를 실행합니다. 설정과 프로젝트별 프로필은 검증 폴더 안의 `private-cli-config`로 격리합니다.

기본 작업 뒤 `node tests/narae/run-formats.mjs <검증 폴더>`는 `visual.nmm`을 1초 길이의 별도 프로젝트로 저장하고 실제 CLI `render` 명령으로 MOV, WebM, GIF를 만듭니다. FFprobe로 코덱과 크기와 길이를 확인하고, FFmpeg로 모든 프레임을 디코드하고, MOV와 WebM의 실제 음성 RMS도 검사합니다.

| 작업 | 실제 검증 대상 |
| --- | --- |
| inventory | 명령 목록, 글꼴, 전환, 효과, 그래픽, LUT, 템플릿, 컴포지션 검색 |
| visual | 영상 가져오기, 자르기 영역, 미러, 색보정, LUT, 디졸브, 도형, 한글 제목, 부분 글자 스타일, 타이프라이터, 자막, 글꼴, 이미지, 마스크, 키프레임, 그룹과 해제, 효과, 프로젝트 저장, MP4 내보내기 |
| editing | 트림과 실행 취소, 분할과 병합, 구간 삭제와 실행 취소, 속도와 실행 취소, 회전, 필터, 오디오 분리, 오디오 가져오기와 볼륨, 복제, 삭제, 실행 취소와 다시 실행 |
| graphics | 직접 작성한 GLSL 검증과 배경 렌더, HTML 글자 프리셋, 프로그램 읽기, 저장, MP4 내보내기 |
| parity | 역재생 생성과 복원, 가변 속도 곡선, 한글 SRT 가져오기와 내보내기, 템플릿 슬롯 지정과 내보내기와 설치와 배치와 텍스트 교체와 편집용 확장, 컴포지션 이동, 프록시 생성과 상태 조회 |
| reopen | 독립 실행에서 저장한 프로젝트를 새로운 실행에서 열기, 클립 수와 타입, 해상도 보존, 재저장 |

이 작업 파일의 존재만으로 런타임 통과를 주장하지 않습니다. 실제 결과 JSON과 `verify-results.mjs`의 통과가 필요합니다. 외부 서비스의 AI 생성, 음성 인식, 클라우드 인증, 화면 녹화와 장치 입력, 임의 확장 모듈 실행, 모든 내보내기 코덱, 모든 템플릿과 모든 GLSL 프리셋의 조합은 이 기본 검증의 범위 밖입니다. 확장 모듈을 설치하거나 외부 서비스에 요청하지 않습니다.
